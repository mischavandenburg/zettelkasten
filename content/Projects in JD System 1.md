# Projects in Johnny Decimal System

I need a way of assigning ID's to projects.

This can be projects for clients, homelab projects, non-tech related projects.

Code repos will be stored with the projects, alongside all other possible artifacts.

I don't need a single place for all projects.

Projects can just be all over the place.

What's the point?

I need to be able to find them and to assign ID's to them that I can reuse across several systems.

That's all.

For the first time I think I have finally found a use for tags in my notetaking system. If I need to pull out all projects for some reason, I will use tags.
