# Handling search for index notes after JD implementation

The Johnny Decimal index numbering influences my search within obsidian.

For example:

22.10 ■ Skool

Will not show up in my search results when I search for Skool, because I have so many other notes with "Skool" in their title.

I'm now moving index notes to a directory "Index" in my vault root. This way, I can search with "ind skool" and I'm certain to get the index note for my particular search term.
